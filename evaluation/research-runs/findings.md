# Exploratory research evaluation, 25 November 2026

Seven paired cases (five individual, two four-person network) ran on the independent research controller with GPT-5.4 via Poe. B disabled acquisition; C could request up to two reads. Both conditions used the same ordered initial evidence IDs for all seven pairs. Conditions were alternated in execution order. One run per condition was performed. The source files are synthetic test conversations, not human-reviewed gold data.

C made one acquisition call on one of seven cases; B made zero. In `owen-fact`, both reviewers identified the missing photography technique; C searched and retrieved source line 35, then answered -0.7 EV and +45 shadow adjustment. B returned insufficient evidence. The AI reviewer scored C complete and B incomplete, while considering B's cautious abstention supported. This is an illustrative within-pair result, not a population-level causal estimate. C used 8,321 logged tokens and exposed 21 unique source messages versus B's 7,116 tokens and 13 messages; elapsed times were 18.701 and 18.183 seconds respectively. Unique source messages and characters are exposure proxies, not a privacy-risk measurement; no provider price or retention was measured.

Across all seven cases, B/C averaged 6,061/8,133 recorded tokens, 15.82/23.49 seconds and 16.14/17.29 unique messages. These are descriptive, include a large non-acquisition network latency difference, and do not isolate acquisition cost. All fourteen API responses returned; there were no recorded output-limit failures in this run. The two conditions differ in the reviewer's acquisition permission and can diverge in subsequent paths even with no call.

The blinded OpenAI Codex AI review found that both conditions missed the disputed Leslie time and chronology issues in Yuki. Both network conditions identified strong candidates, but suggested weak secondary fits or mishandled conflict and eligibility. No C network call occurred, so the data do not test whether adaptive acquisition improves network recommendations. The reviewer previously examined case annotations before the blinded answer review; labels and results were hidden, but this is not an independent human assessment.

Annotation correction: Leslie's later appended 30 November message states 6:45pm, whereas an earlier message says 7pm. Yuki's record has conflicting chronology and a separate earlier M+ visit. These issues invalidate a single unqualified gold time or event chronology. Annotations were written before the run but not independently reviewed beforehand; these corrections must be used in future scoring. The dataset also contains inconsistent weekdays and dates.

Conclusion: adaptive acquisition recovered a missing fact in one case at additional observed token and source exposure cost. The experiment does not establish average quality improvement, a benefit on network ranking, monetary cost, privacy risk, or whether benefits justify costs. Broader paired cases, repeated runs, independently reviewed annotations, human scoring, measured provider exposure and a predefined cost-benefit criterion are needed.
